¿Qué es un Webhook?

📡 Definición

Un webhook es un mecanismo que permite que una aplicación envíe datos a otra de forma automática cuando ocurre un evento específico. Es como un "callback" pero a través de HTTP.

🔄 Flujo

1. Registras una URL en el servicio A
2. Ocurre un evento en el servicio A
3. El servicio A envía datos a tu URL
4. Tu aplicación procesa los datos

⚡ Ventajas

✓ Comunicación en tiempo real
✓ No requiere polling constante
✓ Reduce carga en servidores
✓ Integración simple

🎯 Casos de Uso

• Pagos confirmados (Stripe, PayPal)
• Nuevos usuarios registrados
• Actualizaciones de pedidos
• Notificaciones en tiempo real

Polling vs Webhooks

Aspecto Polling Webhooks
Latencia Alta (depende del intervalo) Baja (inmediato)
Carga del servidor Alta Baja
Complejidad Baja Media
Fiabilidad Media Alta (con reintentos)

Ejemplos de Webhooks

Webhook de GitHub

Recibir notificaciones cuando se hace push a un repositorio:

{
  "event": "push",
  "repository": "mi-repo",
  "branch": "main",
  "commits": [
    {
      "id": "abc123",
      "message": "Fix: corregir bug en auth",
      "author": "usuario@example.com"
    }
  ],
  "timestamp": "2026-10-01T10:30:00Z"
}

Webhook de Stripe

Notificación cuando se confirma un pago:

{
  "id": "evt_1234567890",
  "type": "payment_intent.succeeded",
  "data": {
    "object": {
      "id": "pi_1234567890",
      "status": "succeeded",
      "amount": 5000,
      "currency": "usd",
      "customer": "cus_123456"
    }
  },
  "timestamp": 1696143000
}

Webhook Personalizado

Ejemplo de un webhook personalizado para tu aplicación:

{
  "evento": "usuario.creado",
  "datos": {
    "id": 12345,
    "nombre": "Juan Pérez",
    "email": "juan@example.com",
    "fecha_registro": "2026-10-01T10:30:00Z"
  },
  "intento": 1,
  "timestamp": "2026-10-01T10:30:00Z"
}
